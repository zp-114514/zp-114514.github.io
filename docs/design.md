# 设计说明 (Design)

## 页面区块与浏览顺序
1. Hero - 姓名 + 一句话定位 + GitHub 链接
2. About - 个人简介与专业方向
3. 项目经历 - 三个真实项目卡片
4. 教育背景 - 学校与专业
5. 技能与能力 - 核心技能列表
6. 校园经历 - 校内职务

## 颜色、字体与风格
- 使用模板默认配色（蓝白基调）
- 系统无衬线字体
- 整体简洁、专业

## 响应式要求
- 桌面端：宽屏布局，内容居中
- 移动端：导航折叠为汉堡菜单
- 两端均需无横向溢出、文字可读

## 关键文件
- _config.yml：全部个人信息与内容
- index.md：入口文件
- _layouts/：页面布局
- _includes/：区块模板
- _sass/：样式文件

## 保留与修改
- 保留：模板整体布局、样式系统、响应式设计
- 修改：替换占位名称、示例项目，删除无关社交链接

## 素材来源
- 图标：Font Awesome 免费版
- 不使用个人照片
