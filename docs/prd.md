# 产品需求文档 (PRD)

## 项目目标
建立一个可长期更新的个人项目主页，展示个人简介、项目经历、技能能力和联系方式。

## 用户与场景
- 目标访问者：同学、教师、未来项目伙伴或实习招聘者
- 最先寻找的信息：个人定位与专业方向、项目经历、技能能力
- 希望访问者记住：一位具备商业+数据交叉学科背景的金融科技方向学习者

## 本期范围
- Hero：公开称呼 + 一句话定位
- About：真实个人简介与专业方向
- Skills：核心能力与工具
- Projects：至少 1 个真实项目卡片
- Contact：GitHub 主页链接

## 本期不做
- 不要求从零编写全部 HTML/CSS/JavaScript
- 不加入登录、数据库、支付、复杂后台或访客追踪
- 不公开私人手机号、住址、身份证件或其他敏感信息

## 成功标准
- 页面可公开访问（GitHub Pages）
- 五个基本区块齐全，内容真实，无模板占位
- 桌面端与手机端均可读，无明显溢出或遮挡
- 导航、项目链接、联系方式可用
- 过程材料完整（PRD、Design、Checklist、报告、截图）

## 隐私边界
- 不公开：手机号、住址、身份证号、课程邀请码、密码、API Key
- 公开：姓名、邮箱（QQ邮箱）、GitHub 主页、教育背景、项目经历
