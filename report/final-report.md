### 问题2：本地文件夹与 GitHub 仓库长期不同步
网页端修改 _config.yml 和 docs/ 后，本地文件夹仍为原始模板版本。
**修复：** 从 GitHub 下载最新 ZIP，替换本地文件夹全部内容，确保本地与线上一致。

### 问题3：模板冗余文件未清理

**修复：** 逐一删除冗余文件和文件夹，仅保留网站运行必需的文件。

### 问题4：SSL 网络报错导致首次提交失败
Cloudflare WARP 代理干扰，提交命令因 SSL 错误无法连接服务器。
**修复：** 断开代理直连网络，在 PowerShell 中重新执行提交命令。

### 问题5：提交认证失败
学号或密码错误导致 401 未授权。
**修复：** 重置平台密码后重新登记，使用新密码完成提交认证。
